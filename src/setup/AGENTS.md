# AGENTS.md — Setup Wizard Package (`src/setup/`) Guide

This directory contains the interactive setup wizard (`horizon-wizard`), domain presets loader, tag alias resolver, and optional AI-assisted source recommendation engine.

Parent guidelines apply from root [`AGENTS.md`](../../AGENTS.md) and [`src/AGENTS.md`](../AGENTS.md).

## 1. Module Map

- `wizard.py`: Core CLI wizard entrypoint (`horizon-wizard` -> `main()`), 6-step setup flow, source table review/toggle, config assembly (`build_config`), and deduplicating merge (`merge_configs`).
- `presets.py`: Domain presets loader (`load_presets`, `fetch_presets`) and keyword matching engine (`match_sources`, `match_domains`). Supports API fetch (`HORIZON_API_URL`) with local JSON fallback.
- `tag_aliases.py`: Multilingual tag alias map (`TAG_ALIASES`), alias resolution (`resolve_tag_alias`), and lookup (`get_tag_aliases`).
- `prompts.py`: System (`RECOMMEND_SYSTEM`) and user (`RECOMMEND_USER`) prompt templates for AI source recommendations.
- `ai_recommend.py`: Async (`get_ai_recommendations`) and sync (`get_ai_recommendations_sync`) wrappers around `ai.client` for fetching LLM source recommendations (`origin="ai"`).

## 2. Core Invariants & Boundaries

1. **Noninteractive & Testable Boundaries**:
   - Modularize wizard steps (`configure_ai`, `get_interests`, `select_sources`, `build_config`, `merge_configs`).
   - Use `rich.console.Console` and `Prompt.ask(..., console=console)` so helper functions can be tested and monkeypatched cleanly without hanging TTY terminals.

2. **Secrets Security**:
   - Configs stored or generated by the wizard MUST ONLY contain environment variable names (`api_key_env`, `url_env`), NEVER literal secrets or tokens.
   - Validate environment variable availability via `os.getenv` without persisting raw values.

3. **Model Validity & Parity**:
   - Assembled configs from `build_config()` and `merge_configs()` must instantiate and validate against Pydantic models in `src/models.py` (`Config`, `SourcesConfig`, `AIConfig`, etc.).
   - Default profile lists, thresholds, and HackerNews fallback behavior must remain synchronized with `data/config.example.json`.

4. **Public CLI & Path Compatibility**:
   - Standard argument flags (`-d`/`--data-dir`, `-c`/`--config`, `-l`/`--log-level`) are wired via `src/_cli.py`.
   - `StorageManager` owns config loading/saving and backup creation.
   - Preset discovery checks `<data_dir>/presets.json` before falling back to `data/presets.json`.

5. **Offline & Test Isolation**:
   - Remote API preset fetching (`presets.py`) respects `HORIZON_OFFLINE` environment variable and `prefer_api` flags.
   - All tests in `tests/test_setup_wizard.py` must run offline with zero network or paid API calls.
