# Horizon

AI-управляемая система агрегации информации: собирает материалы из десятка
источников, оценивает их моделью, обогащает веб-поиском и публикует ежедневный
дайджест.

[Смотреть дайджесты :material-arrow-right:](digest/index.md){ .md-button .md-button--primary }

## Что это

Пайплайн из семи стадий — сбор, дедупликация, оценка, фильтрация, обогащение,
рендеринг, доставка. Источники: Hacker News, RSS, Reddit, Telegram, Twitter/X,
GitHub, OpenBB, OSS Insight, GDELT, Google News и **YouTube-каналы** с
расшифровкой речи.

Модель настраивается: подходит любой OpenAI-совместимый бэкенд.
