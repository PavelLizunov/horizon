# ARC Raiders profile

Use this profile for developments, patch notes, updates, gameplay mechanics, datamines, leaks, rumors, playtest events, and community discussions specifically concerning the video game **ARC Raiders** (developed by Embark Studios).

Typical items include:
- Official game updates, client hotfixes, store updates with gameplay/fair-play changes, seasonal expeditions (e.g. Expedition 5), and content roadmap announcements from Embark Studios, Steam News, or Help Center.
- Playtest schedules, beta tests (e.g. PvE Toggle test), technical alpha reports, server status, and release date announcements.
- Weapon, gear, gadget, and skill tree balancing (Survival, Mobility, Conditioning), and game economy adjustments in Speranza.
- ARC machine behaviors (Drones, Snitch, Spotter, Rocketeer, etc.), AI combat mechanics, extraction loops, and PvPvE surface encounter dynamics.
- Verified leaks, datamined files (weapons, upcoming weekly trials), development rumors, and interviews with Embark Studios developers.
- Community guides, high-impact player findings, and tactical meta shifts from r/ArcRaiders or gaming media.

Evidence and verification rules:
- Clearly separate official announcements from datamined content. A datamined asset or string confirms presence in a client build, but is not proof of release date or guaranteed shipping.
- For duplicate reporting, prioritize original developer statements or primary patch notes over secondary rewrites.

Do not use this profile for unrelated video games (e.g. The Finals, Helldivers, generic shooters), unrelated Embark corporate finance news without game relevance, low-effort gameplay clips without context, or vague clickbait rumors lacking any concrete details.
