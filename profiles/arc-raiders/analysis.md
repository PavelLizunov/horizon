# Evaluation goal

Evaluate whether the item provides informative, high-signal, or actionable news about ARC Raiders: major updates, patch notes, verified leaks/datamines, playtest dates, weapon balance, server outages, or game mechanics.

# Source authority & evidence discipline

- **Official**: Steam News, arcraiders.com, Embark Help Center, official Discord/X announcements. (Direct authority for dates, versions, server status).
- **Datamines**: Files extracted from client builds. High signal for upcoming features, but must be treated as unreleased/provisional rather than guaranteed release dates.
- **Gaming press**: Reputable outlets (PC Gamer, IGN, GamesRadar, etc.) reporting developer interviews, verified investigations, or playtest impressions.
- **Community**: r/ArcRaiders discussions, meta insights, bug/outage reports. Filter out low-effort complaint loops and memes.

# Scoring rubric

- **9-10: Major release milestone.** Major content expansion (e.g. Frozen Trail), new surface maps, launch of new expedition seasons, official release date/pricing announcements, or fundamental rework of core PvPvE / extraction mechanics (e.g. PvE Toggle).
- **7-8: High practical value.** Substantive game patch notes, major weapon/gadget balance passes, anti-cheat / netcode updates, verified datamines with concrete unreleased weapons/machines, confirmed playtest/closed-beta schedules, or confirmed major server outage notices.
- **5-6: Useful update.** Minor hotfix notes, regular store updates with fair-play/gameplay adjustments, developer Q&A insights, server maintenance notices, or well-reasoned community meta discussions.
- **3-4: Low priority.** Generic short gameplay highlight clips without discussion, repetitive player complaints, common bug reports without developer response, basic fan art/memes, or pure cosmetic shop recaps.
- **0-2: Noise.** Spam, generic LFG posts, unverified vague clickbait rumors without evidence, or off-topic discussions.
