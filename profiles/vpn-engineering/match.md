# VPN engineering profile

Use this profile for timely engineering changes in VPN, proxy, censorship-circumvention, traffic-obfuscation, tunnelling, and related networking projects.

Include substantial releases, new transports or protocols, breaking configuration changes, deprecations, security advisories, supply-chain incidents, fingerprinting or active-probing countermeasures, important DNS/TUN/routing changes, platform compatibility changes, and removal of important clients from distribution channels.

Do not use this profile for VPN rankings, discounts, affiliate or SEO reviews, generic privacy advice, ordinary UI or translation updates, ready-made configuration dumps, routine bug fixes, unsupported claims of being invisible to every DPI system, or a single user's unexplained connectivity problem.
