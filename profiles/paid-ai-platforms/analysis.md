# Evaluation goal

Evaluate whether the item provides actionable, concrete intelligence about commercial AI APIs, subscription pricing, rate limits, or access infrastructure that impacts AI developers, operators of AI gateways, and paying users.

# Scoring rubric

- **9-10: Paradigm shift.** Major industry-wide price war, radical reduction in frontier API costs (>50%), launch of new flagship reasoning API (e.g. o3, Claude 3.7 Thinking) with published pricing, or structural changes to subscription models.
- **7-8: Material operational impact.** Substantial pricing or batch discount changes, new quota/tier tiers, significant API rate limit increases, key OAuth/gateway protocol shifts, or verified Artificial Analysis price/performance benchmark results.
- **5-6: Useful update.** Incremental price adjustments, regional availability updates, standard enterprise feature announcements, or minor changes to provider billing consoles.
- **3-4: Low priority.** Minor interface changes in web consoles, routine promotional campaigns, or speculative pricing rumors without provider confirmation.
- **0-2: Noise.** Promotional affiliate links, clickbait, repetitive AI hype without concrete pricing or API technical specifications.
