# Paid AI platforms & APIs profile

Use this profile for timely, concrete developments in commercial AI platforms, paid frontier APIs, subscription models, pricing changes, rate limits, and access infrastructure.

Typical items include:
- Token pricing reductions, batch API discounts, caching discounts, and pricing comparisons across major providers (OpenAI, Anthropic, Google Cloud Vertex/Gemini, DeepSeek, xAI, Alibaba DashScope, Kimi, MiniMax).
- Subscription tier shifts and quota changes (ChatGPT Plus/Pro, Claude Pro/Team/Enterprise, Google One AI Premium/Antigravity, Codex, Copilot).
- API operational policies: rate limits (RPM/TPM), Tier progression rules, session affinity, token bucket enforcement, and cooldown semantics.
- Infrastructure and gateway integration: reverse-engineered OAuth/session gateways (CLIProxyAPI, KeyGuard), egress proxying, geoblock circumvention, and provider auth rotations.
- Objective latency, throughput, and cost-efficiency benchmarks (e.g. Artificial Analysis quality-per-dollar indices).

Do not use this profile for pure open-source model weights without commercial API implications, generic consumer marketing, non-technical hype, or corporate PR devoid of concrete pricing, quotas, or API specifications.
