# AI agent harnesses & runtimes profile

Use this profile for substantive developments in AI agent execution harnesses, autonomous runtime environments, sandboxing, tool protocols, and graph-based execution architectures.

Primary priority focus areas:
- **Core harnesses**: DeepSeek Harness (DSH) and Hermes Agent (`NousResearch/hermes-agent`, Hermes autonomous agent runtime, skills, execution loops).
- **Graph loops and graph architectures**: Cyclic agent execution loops, DAG workflows, graph state machines, graph control loops in agent harnesses (e.g. LangGraph, graph-based agent orchestration, supervisor-worker graph loops).
- **Runtime sandboxing & security**: Filesystem jail containment (bubblewrap, Docker, microVM, macOS seatbelt), permission escalation gates, and terminal isolation policies.
- **Interoperability & tool protocols**: Model Context Protocol (MCP) specifications, SDK releases (TypeScript, Python), official/community MCP server implementations, and tool-call schema standards.
- **Multi-agent coordination**: Coordinator-worker swarms, subagent spawning, background agent persistence, and resident child communication.
- **Rigorous agent benchmarks**: SWE-bench, LiveCodeBench, WebArena, HumanEval execution integrity, and agent regression analysis.

Do not route here:
- Noisy, repetitive coding assistants or IDE extensions (Cline, Roo Code, etc.) with minor patch releases.
- Generic prompt templates, simple single-turn chatbot wrappers without environment access.
- Marketing announcements of "AI assistants" without terminal/tool capabilities, or speculative thought pieces without code or architecture.
