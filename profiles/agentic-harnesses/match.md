# AI agent harnesses & runtimes profile

Use this profile for substantive developments in AI coding agents, autonomous terminal environments, agent execution harnesses, runtime sandboxing, and agent interoperability protocols.

Typical items include:
- Major releases and architectural changes in coding agents and execution environments: DeepSeek Harness (DSH), Claude Code CLI, OpenCode / OpenDesign, Aider, Cline / Roo Code, OpenHands (OpenDevin), Goose, Cursor, Windsurf, AutoGen, OpenAI Swarm.
- Execution sandboxing and security architectures: filesystem jail containment (bubblewrap, Docker, microVM, macOS seatbelt), permission escalation gates, and terminal isolation policies.
- Interoperability and tool protocols: Model Context Protocol (MCP) specifications, SDK releases (TypeScript, Python), official/community MCP server implementations, and tool-call schema standards.
- Multi-agent coordination mechanisms: coordinator-worker swarms, subagent spawning, background agent persistence, and resident child communication.
- Rigorous agent benchmarks: SWE-bench, LiveCodeBench, WebArena, HumanEval execution integrity, and agent regression analysis.

Do not use this profile for generic prompt templates, simple single-turn chatbot wrappers without environment access, marketing announcements of "AI assistants" without terminal/tool capabilities, or speculative thought pieces without code or architecture.
