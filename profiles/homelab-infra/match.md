# Homelab, Proxmox & AI infrastructure profile

Use this profile for practical engineering developments in home server infrastructure, hypervisors, virtualization, self-hosted services, mesh networking, and private AI compute nodes.

Typical items include:
- Proxmox VE releases, kernel updates (Linux 6.8+), Proxmox Datacenter Manager (PDM), ZFS storage management, and LXC container optimization.
- GPU passthrough, NVIDIA Linux open-kernel drivers, CUDA 12/13 updates, NVML monitoring, and running local LLM inference engines (ExLlamaV3, vLLM, llama.cpp) on dedicated consumer GPUs (e.g. RTX 5060 Ti / RTX 4090).
- Mesh VPN and zero-trust remote access: Tailscale (MagicDNS, Tailscale Serve/Funnel, Subnet Routers, ACLs), Headscale, and WireGuard site-to-site tunnels.
- Lightweight homelab monitoring and telemetry: Beszel (PocketBase/SQLite hub and agent), Pulse hypervisor dashboard, Prometheus/Grafana exporters.
- Essential self-hosted server utilities: Caddy v2 reverse proxy, RustDesk (hbbs/hbbr), Vaultwarden (Bitwarden-compatible password manager), and self-hosted AI gateways (CLIProxyAPI, KeyGuard, LiteLLM).
- Hardware and SBC guides: mini-PCs, Mac mini Apple Silicon homelab nodes, Raspberry Pi utility nodes, NFS storage shares, and power/thermal efficiency tuning.

Do not use this profile for enterprise multi-million dollar cloud datacenter news with no self-hosting relevance, consumer smart-home gadget unboxings, generic NAS marketing, or unverified hardware rumors.
